OPEN ROAD Phase 0 Windows x64 prototype build.

This is an engine/rendering/benchmark spike, not the completed motorcycle simulator. It contains a procedural non-production bike fixture, 1 km road, 50 kinematic traffic fixtures, horizontal lens pass, mirror targets, and benchmark mode. See the included README, BENCHMARKING.md, and ASSET_LICENSES.md.

The Windows build is unsigned and may trigger SmartScreen. Only run binaries downloaded from this repository's GitHub Actions/Release artifacts and review the source/license documentation. No code-signing claim is made.
