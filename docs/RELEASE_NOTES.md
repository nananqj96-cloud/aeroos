OPEN ROAD Phase 0 Windows x64 prototype.

This build contains a small procedural road, bike and traffic fixtures, chase/cockpit cameras, mirror views, a horizontal lens effect, and a benchmark. It is a prototype, not the completed motorcycle simulator. See the included README, BENCHMARKING.md, ASSET_LICENSES.md, and GODOT_ENGINE_LICENSE.txt.

The Windows executable is unsigned and may trigger SmartScreen. The build is intended to be a standalone single-file `.exe`. Its CI smoke test checks startup only; it does not certify graphics quality or target-PC performance. Run the benchmark on the target PC before making a performance claim.
